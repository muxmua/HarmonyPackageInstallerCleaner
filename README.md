# 鸿蒙应用安装器净化

## 功能

每项功能都有独立开关，默认全部开启：

1. 广告净化
2. 商店推荐净化
3. 身份验证全部跳过
4. 风险检测全部跳过
5. 风险文字和危险图标清理
6. 纯净模式拦截跳过
7. 未知来源限制跳过
8. 匿名来源弹窗自动确认
9. 推广 UI 清理
10. 修复旋转锁定 bug

身份验证包括儿童模式、FusionAuth 指纹/人脸/PIN、AGD 账号校验。  
风险检测包括本地 HSM、在线风险、AGD 风险等待和 Anco 风险入口。

## 构建

要求：

- JDK 17
- Android SDK Platform 34
- Build Tools 34.0.0
- Gradle 8.7 或 Android Gradle Plugin 8.5.2 兼容版本



## 如何使用

1. 在LSPosed中
2. 启用“鸿蒙应用安装器净化”
3. 作用域勾选 `com.android.packageinstaller`
4. 重启设备
5. 打开模块设置，确认开关
